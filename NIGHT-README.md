# WinDirStat Night

Личный форк WinDirStat 2.8.0 с ночным оформлением. Исходный проект: https://github.com/windirstat/windirstat, тег `release/v2.8.0`, коммит `579dd76d6870b4efbb9497644698155fdab84284`.

## Изменения

- Ночная тема включена по умолчанию независимо от темы Windows. Явный выбор пользователя в настройках сохраняется.
- Тёмная графитовая палитра меню, окон, списков и диалогов; светлый текст и более читаемые приглушённые подписи.
- Зелёное выделение строк и активной вкладки. Активная вкладка также выделена жирным шрифтом.
- Для типов файлов используется палитра из 64 различных тёмно-серых оттенков (#282828–#676767). Самые распространённые типы получают отдельные оттенки; последующие используют последний оттенок палитры. Выравнивание яркости цветов отключено, чтобы серые оттенки не сливались. Разделители и обводка чёрные; объёмный блик отключён.
- В настройках карты можно выбрать **Тёмно-серую** или **Цветную (исходную)** палитру. Предпросмотр обновляется сразу; **Применить** или **ОК** перекрашивает карту и легенду без повторного сканирования. **Отмена** не применяет неподтверждённый выбор. Палитра сохраняется между запусками, интерфейс остаётся ночным.
- Цветной режим использует все 18 цветов исходного WinDirStat 2.8.0 в исходном порядке и его стандартное объёмное затенение. При переключении режима восстанавливаются параметры его отрисовки: цветной — исходные, серый — плоские тёмные области с чёрной сеткой. Стиль компоновки карты сохраняется.
- В сером режиме выделенные файлы получают свои классические цвета и объёмное затенение. Выбор папки окрашивает её содержимое, выбор расширения — файлы этого типа. После снятия выделения они снова серые. Остальная карта остаётся тёмной; пересканирование не требуется.
- Крупные значки панели инструментов и чередование фона строк включены по умолчанию.
- Отдельное имя WinDirStat Night и отдельная ветка настроек в реестре.
- Portable-комплект с русским интерфейсом и настройками рядом с EXE.

Ночная тема использует поддержку Windows 10 1809 и новее, как в исходном проекте. Сканирующее ядро не менялось.

## Сборка

Нужны Visual Studio 2022 Build Tools, инструменты C++ x64/x86, MFC v143 и Windows SDK. Из корня репозитория:

```powershell
.\build-night.ps1 -Platform x64
```

Скрипт собирает программу, проверяет экспорт тестовой папки и создаёт `publish\WinDirStat-Night-x64`. В GitHub Actions доступен процесс `Night portable`: после успешного выполнения скачайте одноимённый артефакт x64.

## Запуск

Распакуйте комплект в доступную для записи папку и запустите `Start-WinDirStat-Night.cmd` или `WinDirStat.exe`. Сохраните `WinDirStat.ini` рядом с EXE. Язык и тему можно изменить в общих настройках; смена темы требует перезапуска.

Для смены цветов карты откройте **Настройки → Настроить WinDirStat → Карта каталогов → Палитра карты**, выберите режим и нажмите **Применить**. Смена палитры не требует перезапуска.

## Проверка

GitHub Actions собирает x64-программу, запускает тесты логики выделения (один/несколько файлов, вложенные папки, расширения, снятие выделения), сверяет классическую палитру с оригиналом и проверяет сканирование в обоих режимах.

`night\Test-NightScan.ps1` создаёт отдельную небольшую папку с тремя файлами, включая пустой файл и русское имя, запускает экспорт CSV и сверяет пути, количество файлов, размеры и сохранение палитры. Он не использует ваши папки для тестовых записей. Визуальную проверку окон необходимо выполнять отдельно.
